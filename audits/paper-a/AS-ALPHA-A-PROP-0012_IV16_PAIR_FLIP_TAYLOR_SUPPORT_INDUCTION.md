# PROP-0012 IV-16 — Pair-Flip Taylor-Support Induction by Perturbation Order

**Date:** 2026-11-21  
**Scope:** Close the fixed-finite-N conditional support/order lemma used by IV-15, including first derivatives with respect to independent edge perturbations.  
**Disposition:** ANALYTIC-PARTIAL PASS for the combinatorial support induction under the finite-dimensional analytic eigenvector/Taylor setup. This is not a mechanically checked recurrence or Lean proof.

## 1. Setup

Use the uncoupled x-basis indexed by flip subsets F of {1,...,N}; the vacuum is F=empty. The perturbation is a sum of pair-flip operators, each supported on an edge e={i,j} and mapping a basis set F to F symmetric-difference e. Introduce r as the common weak-coupling parameter and independent edge variables u_e in a fixed neighborhood, so each interaction coefficient is r times an analytic function of u_e.

For finite N and the nondegenerate vacuum at r=0, the normalized ground-state vector (or a locally analytic gauge-fixed eigenvector) has a convergent Taylor expansion in r locally:
c_F(r,u)=sum_{n>=0} c_{F,n}(u) r^n.

## 2. Induction statement

For every even flip set F, all Taylor coefficients below ceil(|F|/2) vanish:
c_{F,n}(u)=0 for n<|F|/2.
Equivalently, c_F=O_N(r^{|F|/2}). The vacuum F=empty is the exception only in the sense that it has a nonzero zeroth-order coefficient; the same lower-bound statement is vacuous there.

## 3. Support induction

At Taylor order n, a contribution generated by n pair-flip interaction insertions follows a path F_0=empty, F_k=F_{k-1} symmetric-difference e_k, with each e_k a two-site set. The final set is the symmetric difference of n edge-pairs. Since each insertion can add at most two previously absent sites, |F_n|<=2n. Thus any coefficient at order n supported on F must satisfy |F|<=2n, or n>=|F|/2. Cancellation among paths can remove coefficients, but cannot create support at a lower order than the path-count bound.

The eigenvector Taylor recursion also contains scalar energy corrections and normalization/gauge terms. These multiply amplitudes already present at lower orders and do not introduce new flip sites; hence they preserve the same support bound. This is the key recursion-preservation step, stated at the support level rather than as an explicit coefficient identity.

## 4. First edge derivatives

The u_e dependence enters only through analytic interaction coefficients on pair-flip insertions. Differentiating a Taylor coefficient with respect to a fixed u_e differentiates a coefficient/path weight, not its flip-set transition. It therefore does not change the number n of r factors or the support of the associated paths. Consequently the same lower-order vanishing holds for first edge derivatives, and ∂_{u_e}c_F=O_N(r^{|F|/2}) for non-vacuum F under the stated analytic recursion.

## 5. Application to IV-15 environment tails

For nonempty even E in environment {3,...,N}, |E|>=2:
- c_E=O_N(r^{|E|/2}), hence at least O_N(r) for |E|=2;
- c_{E∪{1,2}}=O_N(r^{(|E|+2)/2}), hence at least O_N(r^2) for |E|=2.

Products in exact environment sums then give R_L=O_N(r^2), R_X=O_N(r^3), R_S=O_N(r^4); the same first-derivative orders follow by product rule. This supports the IV-15 tail order counting.
