# IV-63 — Reducible-Path Identification and Classification

## Scope and convention
Enumerate all distinct ordered four-edge sequences from four-edge multisets over the 28 pair edges on an 8-vertex pool. A vacuum return is flagged when the flipped set after operation 2 or 3 is empty. This is a combinatorial flag, not a perturbative correction rule.

## Exhaustive totals
- Total ordered sequences: 614,656.
- Vacuum after step 2: 21,952.
- Vacuum after step 3: 9,408.
- Both step-2 and step-3 vacuum: 0 in this enumeration.
- Total with a vacuum prefix: 31,360.

## Classification by repeated edges
| Vacuum prefix | Repeated edge occurrences in full 4-operation sequence | Count |
|---|---:|---:|
| Step 2 | 1 | 19,656 |
| Step 2 | 2 | 2,268 |
| Step 2 | 3 | 28 |
| Step 3 | 0 | 8,400 |
| Step 3 | 1 | 1,008 |

For step-2 vacuum, the first two operations must be the same pair edge, so the prefix immediately returns to the initial state. Step-3 vacuum requires the first three edge operations to have odd-degree parity cancel; in this simple pair-edge graph it is a triangle prefix. The fourth operation may repeat one of the prefix edges (1,008 cases) or be distinct (8,400 cases).

## More detailed signatures
Step-2 vacuum:
- 3 distinct edges, 1 edge repeat, 0 repeated states: 19,320
- 3 distinct edges, 1 edge repeat, 1 repeated state: 336
- 2 distinct edges, 2 edge repeats, 0 repeated states: 756
- 2 distinct edges, 2 edge repeats, 1 repeated state: 1,512
- 2 distinct edges, 2 edge repeats, 2 repeated states: 28

Step-3 vacuum:
- 4 distinct edges, no edge repeat, no repeated state: 8,400
- 3 distinct edges, 1 edge repeat, no repeated state: 336
- 3 distinct edges, 1 edge repeat, 1 repeated state: 672

## Interpretation
- Step-2 vacuum sequences are generated by a repeated first edge (e1=e2), which creates a zero-energy intermediate state. This makes the naive product of three resolvent denominators invalid.
- Step-3 vacuum sequences have triangle prefix e1,e2,e3, so the first two intermediate states are non-vacuum and the third is vacuum. They are a distinct structural family.
- Repeated edge occurrence and repeated flip-state occurrence are not identical classification criteria.
- These counts do not prescribe whether or how reducible contributions should be subtracted, resummed, or incorporated into energy/normalization corrections.

## Limitations
No coupling-weighted amplitudes, resolvent signs/prefactors, reducible corrections, normalization, fourth-order density matrix, entropy, B-C response, or Lean proof is computed.
